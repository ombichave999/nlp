Practical No. 1: Mini Generative AI – Next Word Prediction

Aim

To understand the basic concept of Generative Artificial Intelligence by developing a simple next-word prediction model using Python.

Theory

Generative Artificial Intelligence (Generative AI) is a branch of AI that creates new content such as text, images, audio, and code by learning patterns from existing data. One of the simplest text generation techniques is next-word prediction, where the system predicts the most probable next word based on previously learned word sequences. This concept is the basic building block of modern Large Language Models (LLMs) like ChatGPT.

Algorithm

  1. Start the program.
  2. Create a list of sample sentences.
  3. Split each sentence into individual words.
  4. Store every word along with its next word in a dictionary.
  5. Display the learned model.
  6. Accept a starting word from the user.
  7. Randomly select the next word from the learned dictionary.
  8. Repeat the process until no next word is available or the desired number of words is generated.
  9. Display the generated text.
  10. Stop.

Practical No. 7: Dimensionality Reduction using PCA

Aim

To implement Principal Component Analysis (PCA) using Python and reduce the dimensions of the Wine dataset for visualization.

Theory

PCA (Principal Component Analysis) is a dimensionality reduction technique used in Machine Learning. In this practical, the Wine dataset containing 13 features is standardized and reduced to 2 principal components.

[15]
import pandas as pd import matplotlib.pyplot as plt from sklearn.decomposition import PCA from sklearn.preprocessing import StandardScaler from sklearn.datasets import load_wine # Load dataset data = load_wine() # Create DataFrame df = pd.DataFrame( data.data, columns=data.feature_names ) # Standardize data scaler = StandardScaler() df_scaled = scaler.fit_transform(df) # Apply PCA pca = PCA(n_components=2) pca_data = pca.fit_transform(df_scaled) print("Original Features:", df.shape[1]) print("Reduced Features:", pca_data.shape[1]) # Visualize PCA results plt.scatter( pca_data[:, 0], pca_data[:, 1], c=data.target, cmap="viridis", edgecolors="k" ) plt.xlabel("Principal Component 1") plt.ylabel("Principal Component 2") plt.title("PCA on Wine Dataset") plt.show()
Original Features: 13 Reduced Features: 2

Conclusion

The practical demonstrated the implementation of PCA on the Wine dataset.

Practical No. 8: Statistical Analysis and Hypothesis Testing for AI

Aim

To apply statistical techniques in Python for analyzing data and understanding how ANOVA and hypothesis testing support data-driven and AI-based decision-making.

Part A: One-Way ANOVA

Problem Statement

Consider the exam scores of students from three different classes. Perform a One-Way ANOVA test.

Class A: [85, 90, 88, 82, 87]
Class B: [76, 78, 80, 81, 75]
Class C: [92, 88, 94, 89, 90]

[16]
import numpy as np from scipy import stats from statsmodels.stats.multicomp import pairwise_tukeyhsd class_A = [85, 90, 88, 82, 87] class_B = [76, 78, 80, 81, 75] class_C = [92, 88, 94, 89, 90] f_statistic, p_value = stats.f_oneway(class_A, class_B, class_C) print("F-Statistic:", f_statistic) print("P-Value:", p_value) alpha = 0.05 if p_value < alpha: print("Reject the Null Hypothesis: There is a significant difference in the mean exam scores.") else: print("Fail to Reject the Null Hypothesis: There is no significant difference in the mean exam scores.")
F-Statistic: 28.583333333333343 P-Value: 2.727133500331835e-05 Reject the Null Hypothesis: There is a significant difference in the mean exam scores.

Part B: One-Sample T-Test

Hypothesized population mean: 70

Scores: [72, 88, 64, 74, 67, 79, 85, 75, 89, 77]

[17]
import scipy.stats as stats import numpy as np student_scores = [72, 88, 64, 74, 67, 79, 85, 75, 89, 77] hypothesized_mean = 70 t_statistic, p_value = stats.ttest_1samp(student_scores, hypothesized_mean) print(f"T-statistic: {t_statistic}") print(f"P-value: {p_value}") alpha = 0.05 if p_value < alpha: print("Reject the null hypothesis: The sample mean is significantly different from 70.") else: print("Fail to reject the null hypothesis: The sample mean is not significantly different from 70.")
T-statistic: 2.6249999999999996 P-value: 0.027583862030934297 Reject the null hypothesis: The sample mean is significantly different from 70.

Part C: Two-Sample T-Test

Compare task completion times between Group I and Group II.

[18]
import scipy.stats as stats import numpy as np group1 = [85, 95, 100, 80, 90, 97, 104, 95, 88, 92, 94, 99] group2 = [83, 85, 96, 92, 100, 104, 94, 95, 88, 90, 93, 94] t_stat, p_value = stats.ttest_ind(group1, group2) print(f"T-statistic: {t_stat}") print(f"P-value: {p_value}") alpha = 0.05 if p_value < alpha: print("Reject the null hypothesis: There is a significant difference in the mean times.") else: print("Fail to reject the null hypothesis: There is no significant difference in the mean times.")
